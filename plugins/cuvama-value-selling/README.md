# Cuvama Value Selling

Free value selling skills for Claude, from Cuvama. Your value leader sets up your
company's value profile once. After that, anyone on the team can paste discovery
call notes and get a value hypothesis, then turn it into a business case with ROI
and payback. Everything is saved as JSON and Excel files in one shared SharePoint
folder, so the next person or the next conversation picks up where you left off.

## Use it

1. Create a SharePoint folder called **Cuvama Value Selling** and share it with your team.
2. Value leader: say "set up Cuvama value selling" and give your website.
3. Share this plugin with your team (Customize > Plugins > Cuvama Value Selling > Share).
4. Sellers: paste call notes and ask for a value hypothesis, then ask for the business case.

Needs the Microsoft 365 connector, with write actions allowed, and code execution turned on.

## Data

The plugin stores nothing itself and sends nothing to Cuvama. Claude reads your website
and writes files only to your own SharePoint folder, through your Microsoft 365 connector.
