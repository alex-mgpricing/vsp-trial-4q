# Cuvama Value Selling

For sellers, pre-sales and value teams. Paste notes from a prospect call and ask for a
value hypothesis; later, ask for the business case for that prospect. Claude uses your
company's value profile, set up by your value leader with the Cuvama Value Selling -
Admin plugin, and saves everything to your team's SharePoint folder.

## Data

The plugin stores nothing itself and sends nothing to Cuvama. Claude reads and writes
files only in your team's SharePoint folder, through your Microsoft 365 connector.
