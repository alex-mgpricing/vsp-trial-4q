# Cuvama Value Selling - Admin

For value, sales and enablement leaders. Say "set up Cuvama value selling" in Claude
and give your website and the SharePoint folder your team should use. Claude drafts
your value profile from your website and case studies, saves it to that folder, and
builds a ready-made value selling plugin for your team. You upload it and share it with
your team in two clicks; they never need to know where the files live.

## Data

The plugin stores nothing itself and sends nothing to Cuvama. Claude reads your website
and writes files only to the SharePoint folder you choose, through your Microsoft 365
connector.
